# Fri-Dine 🍽️

Fri-Dine is an Android restaurant table-booking application that helps users discover restaurants, explore dining options, and reserve tables conveniently.

## Features

* Discover popular restaurants and cafés.
* Explore Pakistani cuisine, including karahi and other traditional dishes.
* Browse restaurant information and available booking options.
* Reserve tables for dining.
* User authentication and restaurant discovery.

## Technology Stack

* React Native
* Expo
* JavaScript
* Firebase

## Getting Started

1. Clone this repository.
2. Install dependencies using `npm install`.
3. Configure your Firebase credentials and environment variables locally.
4. Start the application using `npx expo start`.

## Security

Never commit `.env` files, private credentials, or service-account keys to GitHub.
